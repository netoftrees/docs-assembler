# Support

## Getting Help

We want you to succeed with Docs Assembler. Here's how to get help, depending on what you need.

### Quick Questions & How-To's

**GitHub Discussions** - best for questions, ideas, and general help  
https://github.com/netoftrees/docs-assembler/discussions

- How do I structure maps for my use case?
- Can Docs Assembler do X?
- Sharing your setup or workflow

### Bugs & Feature Requests

**GitHub Issues** - for reproducible bugs and concrete feature proposals  
https://github.com/netoftrees/docs-assembler/issues

Before opening an issue, please:
- Search existing issues to avoid duplicates
- Include VS Code version, extension version, and OS
- For bugs: steps to reproduce, expected vs. actual behaviour
- For features: describe the problem, not just the solution

### Direct Contact

**Email:** team@netoftrees.com

Use email for:
- Security vulnerabilities (see [SECURITY.md](./SECURITY.md))
- Commercial enquiries (Docs Rescue service, custom development)
- Anything sensitive or private
- If GitHub isn't accessible to you

We typically respond within 2 business days.

### Documentation & Self-Help

- [Live Demo](https://netoftrees.com/docs-assembler-demo/) - see Docs Assembler in action
- [Demo Repository](https://github.com/netoftrees/docs-assembler-demo/) - explore the source maps
- [Template Repository](https://github.com/netoftrees/docs-assembler-template/) - ready-to-use starter
- [Display Tool Contract](./DISPLAY_TOOLS.md) - for display tool authors
- [Predictive Pre-fetching White Paper](./PREDICTIVE_PREFETCH_WHITEPAPER.md) - technical deep-dive on localisation architecture
- [CHANGELOG](./CHANGELOG.md) - what's new and what's coming

### Response Times

| Channel | Typical Response |
|---------|-----------------|
| GitHub Issues (bugs) | 3 - 5 business days |
| GitHub Discussions | 5 - 7 business days |
| Email | 2 business days |

We are a small team. We prioritise bugs that affect multiple users and features aligned with our roadmap. We read everything - even if we can't respond immediately.

### What We Don't Support

- **Custom display tool development** - we provide the contract and white paper; implementation is yours
- **General Markdown or Jekyll questions** - please use Stack Overflow or those projects' support channels
- **Legacy versions** - we only support the latest 0.9.x release

### Enterprise & Team Support

For organisations needing guaranteed response times, onboarding assistance, or custom feature development, contact us at team@netoftrees.com to discuss a support agreement.
